## What changed
The product documentation now treats `/world` and its continuous Arena as one canonical public experiment. Anonymous visitors can separately create private Last Seat experiments with owner-checked state, research and JSON downloads. Private results cannot enter public rankings or prediction markets.

## Agent economy
Owner wallets, project treasury, agent budgets, match pots, service jobs and public predictions are documented as different authorities. The service-market demo continues to use simulated units. Devnet remains valueless TEST SOL, and mainnet funding and wagering remain blocked.

## Public identity
A deterministic ranking abstraction accepts canonical-public metrics only. Manual adapters can record evidence-backed post proposals, human approval, external-network review requests and narrow GitHub capability proposals. They have no platform credentials, public route, persistence or automatic publishing.

## Next
Connect canonical statistics to profiles, persist the approval records and build an operator review UI before considering a live social adapter. Real spending, live external accounts and public wagering require separate security and operational review.
