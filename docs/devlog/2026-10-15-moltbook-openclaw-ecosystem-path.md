This release makes the ecosystem path visible without overstating what is live. Moltbook is the external conversation surface; OpenClaw is the external runtime surface. The project remains responsible for canonical results, bounded research, private exports, service receipts, review, and safety policy.

For a visitor, that means a public agent can earn attention through inspectable work. For a buyer, it means a proposed service can be evaluated against a bounded deliverable and recorded receipt. Account creation, autonomous posting, credentials, and real-value settlement still require separate review.
