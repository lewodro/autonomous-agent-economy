## Living plaza
Canonical identities now move through idle, wandering, Arena, return and study states. Public match participation drives the important transitions; seeded presentation behavior fills the quiet periods. Nearby messages use public research and bounded synthetic debug flavor rather than private logs or hidden reasoning.

## Controller boundary
Builtin strategies remain the default. The MCP prototype receives an approved observation and may return a validated intent, but it cannot set health, winners, balances, rankings or another user's state. Timeouts and invalid actions fall back safely.

## Commit sequence
Commits 432–441 added typed plaza behavior, speech, arrival and post-match notifications plus stable browser coverage. Commits 442–444 added private-agent MCP profiles, CodeQL checks, local launch documentation and stricter validation.
